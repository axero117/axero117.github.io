9. 定制博客

你可以根据需要定制博客，包括但不限于：

  • 修改 _config.yml 配置文件，调整博客的基本设置（如标题、描述、语言、URL 等）。
  • 在 source/_posts 目录下创建新的文章。
  • 修改主题样式（编辑主题的 source/css 或 themes 下的样式文件）。

总结

  1. 安装 Node.js 和 Git。
  2. 安装 Hexo 并初始化博客。
  3. 启动本地开发服务器查看效果。
  4. 安装并应用你喜欢的主题。
  5. 创建和编辑文章。
  6. 生成静态文件并部署到 GitHub Pages。

这样，你就完成了 Hexo 博客的搭建。如果你在过程中遇到任何问题，可以随时告诉我！
